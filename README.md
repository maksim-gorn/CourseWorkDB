# shop manager panel

панель управления магазином с crud для техники, категорий, производителей, поставок, продавцов и продаж.

## запуск

```bash
pip install -r requirements.txt
python seed.py
python run.py
```

открыть http://127.0.0.1:5000

## что внутри

- 7 таблиц sqlite
- crud-интерфейс для каждой таблицы
- отчёт о реализации за год (pdf)
- дашборд с диаграммами на главной
